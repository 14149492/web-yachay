# 🦙 Yachay — Sitio Web Oficial & Guía de Uso

Sitio web oficial, interactivo y moderno para la aplicación móvil **Yachay (Aprendizaje de Quechua)**, diseñado con la misma finalidad, arquitectura visual y experiencia de usuario que la página de referencia de Transito Pay.

---

## ✨ Características del Sitio

1. **Header & Hero Andino Dinámico**:
   - Escenario vectorial con montañas andinas (Apus) y Sol Inca (*Inti*).
   - Mascota animada **Yachi** trotando con chullo tradicional y partículas mágicas.
   - Globo de diálogo interactivo con saludos en Quechua al hacer clic.
   - Dual Call-to-Action para explorar la guía o descargar la APK.

2. **Soundboard Fonético Interactivo**:
   - Reproducción de frases esenciales en Quechua (*Allillanchu?*, *Sumaq Kawsay*, *Añay*, *Munakuyki*, *Ama Suwa*, *Tupananchiskama*).
   - Síntesis fonética nativa usando la Web Speech API del navegador.
   - Efectos de sonido reales integrados (`tap.wav`, `correct.wav`, `complete.wav`).

3. **Arquitectura de Características Clave**:
   - Malla curricular gamificada (*El Camino del Saber*).
   - Motor de ejercicios multimodales (opción múltiple, pares, banco de palabras).
   - Biblioteca Andina abierta (cuentos, tradiciones, gastronomía).
   - Traductor de bolsillo con IA y dictado por voz.
   - Liga Andina semanal, medallas incaicas y tienda de ítems.

4. **Guía de Uso Paso a Paso Completa**:
   - **Módulo 1: Guía para Estudiantes** (Bienvenida, navegación del mapa, fase teórica, resolución de cuestionarios y recompensas de nivel).
   - **Módulo 2: Sabiduría Ancestral, Traductor & Comunidad** (Cuentos del Ayllu, traducción por voz, podio semanal y modo offline).
   - Capturas de pantalla reales en alta resolución con visor **Lightbox ampliable**.

5. **Cosmovisión Andina & Preguntas Frecuentes**:
   - Principios de *Ayni*, *Minka* y *Sumaq Kawsay*.
   - Explicación del sistema trivocálico (A, I, U) y ortografía oficial.
   - Acordeón interactivo con dudas comunes sobre modo offline y costo.

6. **Zona de Descarga & Enlaces**:
   - Enlace directo a la APK para Android.
   - Enlace al repositorio oficial en GitHub: [Yessyess22/Yachay-idiomas](https://github.com/Yessyess22/Yachay-idiomas.git).

## 🚀 ¿Cómo Abrir el Proyecto Localmente?

Puedes abrir directamente el archivo `index.html` en cualquier navegador moderno:

- **Doble clic** en `index.html` en el explorador de archivos.
- O bien, ejecutar con Live Server de VS Code o cualquier servidor local estático:

```bash
# Ejemplo con Python:
python -m http.server 3000

# O con npx serve:
npx serve .
```
